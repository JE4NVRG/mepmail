O MepMail publica três pacotes npm. Nenhum é um SDK: a API fala o
protocolo do Resend, então enviar e-mail significa usar os SDKs oficiais do
Resend apontados para a origem da sua instância ([SDKs](/pt-BR/sdks)). Estes
cobrem o que aqueles SDKs não fazem — rodar MCP localmente, mover uma
conta de provedor e ligar o MepMail ao n8n.

| Pacote | Versão-fonte | Node | Papel |
| --- | --- | --- | --- |
| [`@mepmail/mcp`](https://www.npmjs.com/package/@mepmail/mcp) | 0.3.2 | `>=20` | 22 ferramentas da equipe e 6 de caixas Correio, conforme a credencial. [Guia](/pt-BR/mcp). |
| [`@mepmail/cli`](https://www.npmjs.com/package/@mepmail/cli) | 0.2.4 | `>=18` | Migração de contas com plano, aplicação e relatório. [Guia](/pt-BR/cli). |
| [`n8n-nodes-mepmail`](https://www.npmjs.com/package/n8n-nodes-mepmail) | [Consultar npm](https://www.npmjs.com/package/n8n-nodes-mepmail) | n8n | Workflows de envio e caixas Correio. [Guia](/pt-BR/integrations#n8n). |

O [MCP hospedado](/pt-BR/mcp) desta revisão é **0.71.1**, com **79 ferramentas** anunciadas no [server card](https://mepmail.dev/.well-known/mcp/server-card.json). A ferramenta adicional `list_teams` só aparece em grants de todas as equipes. Escopos e permissões podem reduzir a lista efetiva.
{/* package-facts:end */}

Esses valores são gerados dos manifests dos pacotes e registros de ferramentas
na revisão-fonte das docs. Os pacotes npm têm ciclo próprio: consulte os links
do registro para a versão publicada e confira `tools/list` no cliente que você
usa. Uma versão do código não publica automaticamente um novo pacote npm.
O pacote n8n vive em repositório separado e se instala pelo próprio n8n
(Settings → Community nodes).

## @mepmail/mcp — o servidor MCP local

```sh
npx -y @mepmail/mcp
```

Ele fala stdio, então o seu cliente é quem o inicia e o bloco de configuração é
a instalação inteira:

```json title="claude_desktop_config.json"
{
  "mcpServers": {
    "mepmail": {
      "command": "npx",
      "args": ["-y", "@mepmail/mcp"],
      "env": {
        "MEPMAIL_API_KEY": "ms_...",
        "MEPMAIL_BASE_URL": "https://api.mepmail.dev"
      }
    }
  }
}
```

| Variável | Obrigatória | Padrão | Significado |
| --- | --- | --- | --- |
| `MEPMAIL_API_KEY` | para ferramentas da equipe | — | Chave de API do time (`ms_...`) de **Chaves de API** no painel. As ferramentas agem com o alcance dessa chave. Pode ser omitida em cliente somente de caixa postal. |
| `MEPMAIL_BASE_URL` | não | `https://api.mepmail.dev` | Origem da API da sua instância. Defina em uma implantação auto-hospedada. |
| `MEPMAIL_MAIL_TOKEN` | para ferramentas de caixa | — | Chave de agente Correio (`mmb_...` para uma caixa ou `mmt_...` para as caixas selecionadas pela credencial de equipe). Funciona sem chave de API da equipe. |
| `MEPMAIL_MAIL_ORIGIN` | não | `https://mepmail.dev` | Origem do painel que serve o Correio. Defina para o serviço de caixas auto-hospedado. |

Em um cliente somente de caixa, substitua `MEPMAIL_API_KEY` na configuração
acima por `MEPMAIL_MAIL_TOKEN`. Ferramentas da equipe usam a origem da API;
ferramentas de caixa usam a origem do painel. Ambas autenticam diretamente
com a própria chave limitada ao seu escopo, sem OAuth no navegador. A
configuração para Claude Desktop, Cursor e VS Code e a lista completa do
servidor hospedado estão na [página de MCP](/pt-BR/mcp).

## @mepmail/cli — a CLI de migração

```sh
npx @mepmail/cli migrate --from resend
```

Esse é o caminho interativo: conecta ao Resend, permite escolher os recursos,
mostra o plano, pede confirmação, aplica e imprime um relatório. Para CI, rode
primeiro o plano somente leitura — código de saída 2 significa que há algo a
aplicar:

```sh
export RESEND_API_KEY=re_...
export MEPMAIL_API_KEY=ms_...

npx @mepmail/cli migrate plan --from resend --out plan.json
npx @mepmail/cli migrate apply plan.json --yes
```

| Variável | Significado |
| --- | --- |
| `RESEND_API_KEY` | Chave de origem, acesso total. A ferramenta só lê do Resend. |
| `MEPMAIL_API_KEY` | Chave do MepMail, acesso total. |
| `MEPMAIL_BASE_URL` | Origem da API de uma instância auto-hospedada. Sem ela, o alvo é o MepMail Cloud. |

As chaves vêm do ambiente (ou do stdin), nunca são gravadas em disco e são
mascaradas em toda linha de log. Todas as flags, os arquivos de estado e os
códigos de saída estão na [página da CLI](/pt-BR/cli).

## Licença e releases

Os dois pacotes são licenciados em MIT e são publicados do mesmo repositório do
servidor, com linha de versão própria. Nenhum dos dois liga para casa: sem
telemetria, sem checagem de atualização.
